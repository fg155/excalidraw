# Excalidraw Personal 桌面版（开发中）

这是个人定制源码，**目前还不是可直接安装的 Windows/Mac 成品**。

Windows 云端构建配置已准备好，尚未执行。首次启用、推送和下载步骤见 [云端构建指南](./CLOUD-BUILD.zh-CN.md)。

## 目前已接入的功能

- 本地／OneDrive 文件夹中的画布列表，新建、打开、重命名和确认后删除。
- 自动保存、保存按钮、Ctrl/Cmd+S；保存失败时阻止切换画布或正常关闭窗口。
- 检测文件内容版本冲突，保留原文件并将当前编辑保存为冲突副本。
- 本机恢复记录，恢复为新画布，不直接覆盖已有文件。
- 设置独立于程序目录，支持手动导入／导出；导出排除本机文件夹路径和系统权限。
- 自由绘图工具中，起笔前按 Shift 画任意角度直线；近似直线停顿后拉直。可在设置中关闭或调整停顿时间。

## 关于数据与更新

画布使用标准 `.excalidraw` JSON，包括当前画布引用的图片数据。桌面版采用固定应用标识 `io.github.fg155.excalidraw-personal`，设置和恢复记录设计为保存在操作系统的应用数据目录，而不是程序文件夹。

“已保存到本机”不表示已同步到云端。OneDrive 离线同时编辑仍可能产生竞争，请避免在两台离线设备上同时修改同一画布。替换应用前建议额外备份画布文件夹并导出设置；不要删除应用数据目录。

删除画布前会创建本机恢复记录，但恢复记录仅在当前设备，且每张画布最多保留最近 20 个快照，不能代替独立备份。

## 开发入口

依赖安装完成且具备匹配的原生构建环境时，项目根目录脚本为：

```text
yarn desktop:dev       # 仅前端开发服务器；文件功能需要原生应用
yarn desktop:build     # 前端生产构建，不生成 exe/APP
yarn desktop:tauri dev # 原生开发应用（完整编译尚待验证）
```

当前机器的工具配置、验证记录、待办事项见项目根目录 `IMPLEMENTATION_STATUS.md`。代码只在本机修改，未推送 GitHub。
