# Excalidraw Personal 桌面版（开发中）

这是个人定制源码，Windows x64 已成功生成便携预览版，仍在测试中；Mac 版尚未打包。

Windows 云端构建已由用户手动推送并成功运行。后续修正也需手动推送，下载对应新构建的预览包，步骤见 [云端构建指南](./CLOUD-BUILD.zh-CN.md)。

## 目前已接入的功能

- 启动时显示画板首页，卡片展示内容缩略图，可新建、打开、导入、重命名和删除本地／OneDrive 画板。
- 编辑时不显示画板侧栏；左上角按钮保存当前画板后返回首页。保存失败不会离开编辑器。
- 自动保存、保存按钮、Ctrl/Cmd+S；保存失败时阻止切换画布或正常关闭窗口。
- 检测文件内容版本冲突，保留原文件并将当前编辑保存为冲突副本。
- 独立回收站最多保留最近删除的 10 个画板，删除满 10 天自动清理；超出容量先清理最早删除的项目。恢复遇到同名文件时另存，不覆盖。
- 历史自动备份位于设置中的“历史备份”，与回收站分开，旧版已有备份不会因升级被删除。
- 设置独立于程序目录，支持手动导入／导出；导出排除本机文件夹路径和系统权限。
- 自由绘图工具中，起笔前按 Shift 画任意角度直线；近似直线停顿后拉直。可在设置中关闭或调整停顿时间。

## 数位板与拉直行为

- 普通笔画保留笔压；首次识别触控笔时使用可变粗细，之后尊重手动选择的等宽／可变粗细模式。需要驱动向应用报告 `pointerType: pen` 和真实压力。
- Shift／停顿拉直的预览与落笔结果均为标准线条，端点跟随笔尖。转换后的线使用平滑、等宽样式（粗糙度 0），调弯中点不会出现两条分开的手绘线。颜色、设定线宽、透明度保留，但标准线条不保存沿线变化的笔压。
- 桌面版普通直线工具新建的线也使用粗糙度 0，不改变矩形、箭头等其他工具的偏好。之后仍可手动调整选中线条的样式。
- 不改变普通自由笔画的样式偏好，不自动修改以前画好的线。旧线可选中后把粗糙度改成最平滑。
- 自动测试覆盖笔压、悬停、活动笔画中的手掌触碰、侧键不误画、标准橡皮擦输入切换与擦除、缩放、取消和撤销；这些是模拟指针事件，不代表已经验证所有数位板驱动或多指手势。
- 实机验收：在测试画布上轻重交替画曲线 → Shift 起笔拉直 → 松开 Shift 继续移动笔尖 → 停顿拉直后移动端点 → 调弯中点 → 擦除／撤销 → 抬笔悬停。如设备有触摸功能，另试手掌触碰和双指缩放。若异常，记录型号、驱动版本和 Windows Ink 设置，暂不更改驱动配置。

## 关于数据与更新

画布使用标准 `.excalidraw` JSON，包括当前画布引用的图片数据。桌面版采用固定应用标识 `io.github.fg155.excalidraw-personal`，设置和恢复记录设计为保存在操作系统的应用数据目录，而不是程序文件夹。

“已保存”指本机保存，不表示已同步到云端。OneDrive 离线同时编辑仍可能产生竞争，请避免在两台离线设备上同时修改同一画布。替换应用前建议额外备份画布文件夹并导出设置；不要删除应用数据目录。

回收站位于本机应用数据目录，不随 OneDrive 同步。应用启动、访问回收站及运行中的到期计时会清理过期项目；应用关闭期间不会运行后台清理，过期项目在下次启动时删除。自动备份另行保留每张画板最近 20 个快照，不能代替独立备份。

## 开发入口

依赖安装完成且具备匹配的原生构建环境时，项目根目录脚本为：

```text
yarn desktop:dev       # 仅前端开发服务器；文件功能需要原生应用
yarn desktop:build     # 前端生产构建，不生成 exe/APP
yarn desktop:tauri dev # 原生开发应用（需本机原生构建工具）
```

当前机器的工具配置、验证记录、待办事项见项目根目录 `IMPLEMENTATION_STATUS.md`。修改与提交在本机进行，GitHub 推送由用户手动完成。
