Excalidraw Personal — Windows x64 开发预览

1. 将下载的 ZIP 完整解压到一个普通文件夹，不要直接在 ZIP 中运行。
2. 双击 excalidraw-personal.exe；同目录若有 DLL，请保留在一起。
3. 需要 Microsoft Edge WebView2 Runtime；不需要安装 Rust、Node 或 C++ 编译工具。
4. 首次测试请选择单独的测试文件夹，不要使用重要画布的唯一副本。

这不是已验证的正式版本。通过云端编译不等于已通过真实窗口、手写笔和 OneDrive 测试。
程序尚未购买 Windows 签名证书，系统可能显示未知发布者提示。
仅从自己仓库中核对过的构建记录下载；不要为了运行程序而关闭杀毒软件或系统防护。

画布保存在你选择的文件夹。设置与恢复记录保存在独立的系统应用数据目录，
应用设置页会显示该目录。替换程序文件前先关闭应用、备份画布并导出设置。
请保留应用数据目录，不要将“替换程序”理解为删除个人数据。

“已保存到本机”不表示 OneDrive 已同步到云端。避免两台设备离线编辑同一画布。
当前预览阶段也请只打开一个应用实例，跨进程文件锁尚待完善。

初次验证建议：新建测试画布 → 绘图 → 等待保存 → 关闭重开 → 检查画布和设置。
然后测试 Shift 起笔直线、停顿拉直、撤销、图片、重命名和删除后的恢复。
若构建或运行失败，请保留错误文字或截图以便继续排查。
